# みてみてくん 🎬

LINE風トークとスタンプを動かし、販促用の動画として書き出すブラウザ完結型ツールです。画像・会話データはブラウザ内だけで扱われ、サーバーへアップロードされません。

## 使う

公開版: https://yayoi333.github.io/linemmk/

1. 「画像ライブラリ」へスタンプまたは絵文字画像・申請用ZIPを追加します。
2. トークの設定と会話シナリオを整えます。
3. 「プレビュー再生」で確認し、「動画を書き出す」を押します。

MP4書き出しには、最新の Chrome または Edge を推奨します。ブラウザが WebCodecs に対応していない場合は、利用可能な形式でのリアルタイム書き出しに切り替わります。

## 開発・公開

依存関係やビルドは不要です。ローカルでは `index.html` をブラウザで開くか、任意の静的ファイルサーバーで配信して確認できます。

`main` ブランチへのプッシュで GitHub Pages に自動デプロイされます。公開先は https://yayoi333.github.io/linemmk/ です。

## 同梱ライブラリ

- `mp4-muxer.min.js`: [mp4-muxer 5.2.1](https://www.npmjs.com/package/mp4-muxer) を使用しています。
