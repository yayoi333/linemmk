# みてみてくん 🎬

LINE風トークとスタンプを動かし、販促用の動画として書き出すブラウザ完結型ツールです。画像・会話データはブラウザ内だけで扱われ、サーバーへアップロードされません。

## 使う

公開版: https://mitemitekun.pages.dev/

1. 右側の「スタンプをアップロード」から、PNGまたは申請用ZIPを追加します。
2. 左側のスマホ下部パネルでスタンプ・絵文字を選び、会話を組み立てます。

「プレビュー再生」で確認し、「動画を書き出す」で保存できます。ブラウザによってはリアルタイム録画へ切り替わり、WebM形式で保存されます。

## スクショ中心の使い方・動画見本

認証後、アプリ右上の「使い方」から開けます。実画面5枚に、ボタンより余白を取った手描き風の赤丸を重ねています。縦型2種類・横型3種類のMP4を、同じ会話で比較できます。見本のダウンロード用リンクはありません。スクショ・動画は `public/guide/` に保存しています。

ローカル確認: http://localhost:3000/linemmk/ を認証して「使い方」を押します。

## 全機能ガイド

使い方ページ上部の「全機能ガイド」から開けます。URLは `?features`。10章・50項目を、実際の設定画面とスマホ画面／動画プレビューの対応図で解説しています。項目を選ぶと、その設定と表示先が手描き風の赤丸・線で結ばれます。機能検索、画像拡大、スマホ幅での上下表示に対応しています。

ローカル確認: アプリの「使い方」から「全機能ガイド」を押します。

撮影用スクリプトは `scripts/capture-features.cjs`、対応座標は `src/featureScreens.ts`、機能一覧は `src/featureCatalog.ts` です。撮影は素材読み込み・会話入力・設定変更・リアクション追加を実際のアプリ上で実行します。ブラウザの注釈対象は撮影時に位置を取得しています。撮影時のポートは3001です。

再検証は `node scripts/verify-features.cjs`。配布キーは検証用の環境変数 `MITEMITE_TEST_ACCESS_KEY` に渡し、ファイルには記録しません。全項目の画像・注釈座標・切り替え、検索、拡大画像の注釈位置、キーボード操作、スマホ表示、ページ間移動、見本のダウンロードUI削除を確認します。

## アクセスキーと使い方ページの入口

切り出しくんと同様に、`#access=<キー>` を含む専用リンク、または入力フォームで認証します。SHA-256で照合し、認証済みのブラウザは次回から入力を省略できます。他商品と認証を共有しない専用の保存名を使い、照合後はURLからキーを消します。localhostでも認証は必要です。

使い方・全機能ガイドは、認証後にアプリ内のリンクから移動した履歴だけで表示します。直接URLを入力した新しい画面には、アプリから開く案内を表示します。アプリ内で開いた後は、その画面の再読み込みとガイド間の移動ができます。ガイドへの往復で、編集中の会話やアップロード素材は保持されます。

ブラウザ側の簡易制限です。サーバーによる認証・ファイル保護ではなく、静的配信された画像・動画・プログラムのURLへのアクセス自体は防ぎません。

認証の検証は `node scripts/verify-access.cjs`（同じ検証用環境変数が必要）。キーの正誤、専用リンク、URLからのキー除去、認証記憶、他商品の認証との分離、ガイドの直リンク制限、往復・再読み込み・戻る／進む、会話・素材の保持を確認します。

## 検索避けの確認（2026-10-04）

公開前の確認では、公開版のHTML headに `robots` / `noindex` のmetaタグがありませんでした。手元の `index.html` にもなく、プロジェクト内に `robots.txt` もありません。この確認時点の公開版は旧画面で、手元はReact版でした。今回の公開対象はReact版・アクセスキー制限・使い方と全機能ガイドです。HTTPの `X-Robots-Tag` ヘッダーと検索エンジンへの登録状況は未確認です。

今回はアプリ本体の検索設定を変更していません。新規ガイドには `noindex, nofollow` を設定しています。検索避けはアクセス制限ではなく、URLを知る人の閲覧を防ぐものではありません。

## 開発・公開

Node.js 22以降を用意し、次を実行します。

```bash
npm install
npm run dev
```

型検査は `npm run lint`、本番ビルドは `npm run build` です。

本番は Cloudflare Pages の既存プロジェクト `mitemitekun`（https://mitemitekun.pages.dev/）です。`npm run build:cloudflare` でルートパス用の `dist-cf` を生成し、その内容をCloudflare管理画面からプロダクションへアップロードします。GitHub Pagesの自動公開は停止し、旧版の手動公開だけを残しています。

2026-10-05: CLIのOAuth認証は別アカウントでPages権限も不足していたため、既存アカウントにログイン済みのChrome管理画面から公開しました。次回もアカウントと公開先を確認し、認証エラー時に別アカウントへ新規作成しないでください。
